Sunny Bots is the system I use for almost all of my AI-assisted work. It
wraps Claude Code with response hooks that extract structured data into a
local database, a small UI layer for pinning entities I want the model to
remember, and a dispatcher that routes incoming requests to the right
context.

The point isn't to replace Claude Code — it's to add the persistent
context and structured memory that a one-shot CLI tool can't have. Each
client has a folder, each session has a template, and the dispatcher tries
to infer which client I'm asking about before I have to say so.

It's not open source (yet). The architecture is intentionally specific to
how I work, and generalizing it well would be a project of its own.
