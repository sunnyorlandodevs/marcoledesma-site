Stellar Standups is what I use to run async standups on small teams. You
add your team, you write your standup, you read everyone else's. It's
intentionally limited — no notifications, no analytics, no AI summaries.

The first version of this app was called `daily-standup` and it taught me
exactly what I didn't want in the second one. The current version is
called `daily-standup-2`, which is honest if not elegant.

The whole thing runs on Laravel with Reverb for the realtime layer, MySQL
for storage, deployed via Laravel Forge. The code is open source.
